This is a tap for homebrew.

# Add Homebrew tap

```bash
brew tap kasie-zhang/homebrew-tools
```

# Install Packages from tap

```bash
# Show tap info
brew tap-info kasie-zhang/homebrew-tools

# Install kello (trust tap first)
brew trust kasie-zhang/tools
brew install kello
```

# Remove tap

```bash
brew untap kasie-zhang/homebrew-tools
```
